## ⚠️ INSTRUCTIONS FOR MARK — READ FIRST

These prompts are written for **ChatGPT with DALL·E 4** (or DALL·E 3 via the API).
Open ChatGPT, navigate to a new conversation, and paste each prompt exactly as written.
You may need to generate 2–3 variations of each image and choose the best one.

**Colour accuracy note:** AI image generators do not always honour exact hex values.
After generation, open each image in any photo editor (even Preview on Mac) and:
1. Check the overall tone feels like aged vellum (#F2E8D0), not white or grey
2. Check black ink reads as warm near-black, not cool grey
3. Adjust levels/warmth slightly if needed — a slight warm curve is fine

**File format:** Export as PNG. Keep under 400KB where possible (use TinyPNG or Squoosh.app).

**Where to put images:** Place each image in the path listed under each prompt.
Name them exactly as specified — the HTML will reference these exact filenames.

## MASTER AESTHETIC BRIEF

Paste this at the start of a new ChatGPT conversation before running any image prompts.
It sets the session context and improves consistency across all images.

```
I am generating a series of images for a personal website. I need strict aesthetic 
consistency across all images. Please remember these rules for this entire conversation:

STYLE: 16th–17th century woodcut print aesthetic. Highly detailed, hand-carved looking 
linework. Images resemble engravings or woodblock prints from devotional books, alchemical 
manuscripts, and natural history folios of the period 1480–1680.

PALETTE: Only warm black ink (#1A1008), aged vellum/parchment background (#F2E8D0 — 
a warm cream, never white or grey), deep crimson red (#8B1A1A) used sparingly for 
accent marks or rubrication, and occasional aged gold (#C8A84B) only for a single 
highlight element per image. No other colours.

TEXTURE: Images should have visible grain, slight ink bleed at edges of lines, 
and the imperfection of hand carving. They should feel printed, not digital.

COMPOSITION: Centred or symmetrical compositions generally. Dense linework in 
focal areas, with breathing room at edges. No photographs, no modern elements, 
no gradients, no flat vector aesthetics.

ORIENTATION: All images horizontal (landscape) unless specified otherwise.
Aspect ratio: 16:9 unless specified otherwise.

Confirm you understand before I give you the first prompt.
```
